# Notation Quest

A small web app for learning to read Algebraic Chess Notation. Each puzzle takes a real game (or a randomly generated one), picks a random position from it, and challenges you to recreate it — on easy by moving pieces under real chess rules, on medium/hard by identifying or placing hidden pieces while reading the notation. Built with [Svelte](https://svelte.dev) and [chess.js](https://github.com/jhlywa/chess.js) for move validation and game replay; pieces are rendered with the public domain [Chess Cuernavaca](https://github.com/samboy/ChessGraphics) font.
